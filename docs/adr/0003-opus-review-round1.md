# ADR 0003 Claude Opus レビュー 第1回

2026-11-24。対象は ADR 0003 の提案草案。Claude Opus による読み取り専用レビュー。

**判定は要修正。Blocker 1件、Major 6件、Minor 4件。** 件数は指摘一覧から再集計した。

## 指摘

### B1 試作の参考が ADR 0002 D1・D2 の生成・採否を通っていない

Blocker。対象は ADR 0003 草案の 3、4、41、60 行。

PROVENANCE.md(作業ツリー)の ai-0003〜0005 は「ChatGPT Image Generation (model identifier unavailable)」「visually inspected by Codex; owner review pending」。巻き髪の ai-0005 は domain の候補も無い。generate.py(最小サイズ・low を強制)を通っていない。参考は黒ベタの髪、白いつや、太さの変わる線で、D1 の指示(Uniform line weight, no shading)と D2 の品質基準(太さが一定でない→捨てる)に合わない。にもかかわらず opus-rounds の試作が 8 回、これを参考に回っている。

修正案。ADR 0003 に「試作の参考は、R1 の generate.py で作り、R2 で owner が accepted と domain を付けたものだけ」と書くか、ChatGPT の画面で作った参考を例外にするなら、ADR 0002 D1・D2 の改訂(モデル版の記録が無いことの扱い、ベタ・つやのある絵の品質基準)を owner 承認つきで先に行う。それまで ai-0003〜0005 の試作の結果を採否の根拠にしない。

### M1 巻いた長い髪は、既存の髪のモデルと工程の外

Major。対象は ADR 0003 草案の 5、26、29、31、63 行。

ADR 0001 D2 の hair.template は 'short' | 'bob'。Q3 の v1 の 4 種は「短い、ボブ、長い、くせ毛の短い」で、巻いた長い髪は無い。ADR 0002 R9 は U3 の実装と owner 承認が前提で、AGENTS も U3 は U2 の承認後。D2.2 の候補(房の始終点、巻きの間隔、前後)は、新しい髪のモデルの設計にあたる。

修正案。候補のコードが src/ の変更か、tools/ の非出荷の試作かを明記する。src/ なら ADR 0001 D2・Q3 の改訂と U3 の後への配置が要る。試作なら、その描画は製品に入らず、golden に影響しないと書く。最初の対象を、v1 にある型(bob の前髪など)にする代案も比べる。

### M2 部品・可視区間と候補の対応を、誰がどの規則で決めるかが無い

Major。対象は ADR 0003 草案の 17、19、21、26、27 行。

D1 は「人が曲線のラベルと少数の点を付ける」が、ADR 0002 Q8 は owner の指示で人の入力を AI 計測に置き換えた(D4「人による入力…は不要」)。担当も owner・Claude・Codex のどれか不明。参考の見える房が 7、候補の房数が 5 のとき、どの参考の房をどのモデルの房に対応させるか、対応しない房をどう数えるかが無い(D2.3 は別 ID を混ぜないとだけ書く)。独立注釈の差を誰が解くかも無い。

修正案。(1) 注釈者(owner か AI か)と独立注釈者を明記し、Q8 との関係を owner に確認する。(2) モデル側にも房の ID と可視区間を出す契約を定め、候補ごとの対応表(生え際に沿った順など、決定的な規則)を当てはめ前に固定する。(3) 対応しない参考の房には固定の罰則を与える(除外しない)。

### M3 曲線距離が、欠測・短縮・隠れ・自己重なりで退化する

Major。対象は ADR 0003 草案の 19、27、28、48 行。

(a) 隠れた区間を損失から除くので、モデルの房を別の房の後ろに隠すと損失が 0 になる(モデル側の可視区間の決め方が無い)。(b) 点と曲線の距離は順序を見ない。巻きの間隔が 3 周と 4 周で違っても、密な螺旋なら参考の各点の近くにモデルのどこかがあり、両方向の距離が小さい。始点→終点の向きを記録しても、損失で使っていない。(c) 区間の点数が少ないと平均が不安定で、区間の重みも合成の式も無い。前後関係の評価の式(対の一致率か)も無い。

修正案。弧長の対応をとる距離(端点を合わせた弧長パラメータでの点ごとの距離、または離散フレシェ距離)にする。参考の見える長さのうち、τ 以内で覆われた割合(被覆率)を別の項にする。欠測は、参考側の理由つきに限り、モデル側の隠れは罰則にする。合成の式・重み・最小点数を、試作の前に固定する。

### M4 表情をまたぐ位置合わせの基準点が、測られないか、動く

Major。対象は ADR 0003 草案の 35 行。

ADR 0002 D4 は、非中立のマスでは目・眉・口の 13 点だけを測り、鼻(noseTip)は測らない。目尻(eyeX_outer)は、ADR 0001 D3 の smile(tilt +4、squint)と surprise(×1.25)で動く。驚きのマスで目尻から相似変換を求めると、縮尺が大きく見積もられ、目の差分が縮尺に吸収される。「相似変換で比較できない」の閾値も無い。

修正案。プリセットで動かない点(耳・頬の輪郭点・首の付け根・分け目・目の中心の高さ)を、非中立のマスでも測るよう ADR 0002 D4 を改訂するか、中立と同じ縮尺を固定して平行移動だけを推定する。除外の閾値(残差の σ の倍数)を事前に固定する。

### M5 試作の採否と独立評価が、同じ 1 枚の参考の中で閉じている

Major。対象は ADR 0003 草案の 28、29、31、37、48、50 行。

「独立に注釈した区間」も同じ画像・同じ房で、評価の独立性が低い。「描画ルールを 1 つ増やした版」は、同じ参考を見て設計するので過学習する。採否は「並べて判断」で、判定規則が無い(ADR 0002 D8 は事前の固定を求める)。実際、opus-rounds の renderer.mjs には、参考に合わせた個別の定数表がある(round-8 の 123 行 前髪の幅 [10,15,18,8,…]、186 行 ringlets の表)。D2.5 と D4 が禁じる「個別参考を覚えさせる」形だが、ADR はその扱いを書いていない。

修正案。採否の規則を事前に固定する(例: 独立区間の距離が X% 改善、D5 の墨の距離と舞台の見分けやすさが悪化しない)。追加ルールの評価には、設計に使っていない別の巻き髪の参考を使う。手で合わせた試作のコードは非公開の比較物とし、src/ に移さないと明記する。

### M6 実装の依存関係が抜けている

Major。対象は ADR 0003 草案の 31、49、58、59、60、61、62、63 行。

当てはめには、ADR 0002 D5 の評価の処理(Issue #10 の snap:false / hair:false、R5・R6)、R2 の記録と非公開の置き場、R4 の計測が要る。モデル側の意味のある曲線(房の中心線・可視区間)を出す API はまだ無い(D2 の前髪は先の細い塗りで、中心線を持たない)。D5 の「validate を全表情で通らない人物は拒む」も書かれていない。承認後の順序 1 の「既存の道具」が何を指すか不明。

修正案。順序の表に、前提の Issue(#10、R2、R4、モデル側の曲線の出力)と、それぞれの完了条件を足す。試作でも validate(全表情)を通すことを条件にする。

### m1 権利の表と置き場の欠け

Minor。対象は ADR 0003 草案の 41、42 行。

ADR 0002 D9 の表に、注釈の曲線・なぞった SVG・パーツのマスク・重ね合わせ画像の行が無い。試作の参考は 一時作業フォルダ にあり、パーミッションが -rw-rw-r--(他のユーザーから読める)で、ADR 0002 D7 の非公開の置き場(cuzic/manga-face-refs)ではない。AGENTS は PR 本文に前後の画像を求めるが、参考を含む比較画像を PR に貼ってはならないことも書かれていない。

修正案。D9 の表に行を足す。置き場は非公開リポジトリか、権限 600 の手元の置き場に限る。比較画像を PR・Issue に貼らないと明記する(PR にはモデルだけの前後の画像を貼る)。

### m2 房ごとのパラメータの集計の下限

Minor。対象は ADR 0003 草案の 43 行。

「10 件以上から丸めた集計値」でも、房ごと・区間ごとの値は欠測が多く、実際に値のある件数が 10 未満になりうる(例: 肩の前の房が 3 件にしか見えない)。

修正案。パラメータごとに、欠測でない独立の参考が 10 件以上あることを集計の条件にする。

### m3 正規化の分母(顔の幅)が、巻き髪で欠測しうる

Minor。対象は ADR 0003 草案の 48 行。

頬の横に房がかかると、ADR 0002 D4 の cheekL/R が隠れ、顔の幅が測れない。

修正案。段 a の相似変換の縮尺(モデル単位)か、目の中心の間隔で正規化する。

### m4 3 表情だけの確認では、ADR 0001 D7 の 8 表情の門を見落とす

Minor。対象は ADR 0003 草案の 47、49 行。

共有部品(髪・輪郭)を変えると、8 表情すべての舞台の見分けやすさが変わる(前髪の長さが眉を隠す、など。ADR 0001 D3 の 1 回目の原因)。

修正案。共有部品を変えた候補は、8 表情の stage.svg と pnpm measure --check の値も添えて比べる。
