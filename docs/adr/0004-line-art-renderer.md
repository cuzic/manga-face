# ADR 0004: 描き方を白黒の線画に移す — 言葉の仕様から描き直す目と顔、パラメータで描く房、段ごとの切り替え

- 状態: **提案**(2026-11-25。owner が方向を承認(「推奨案で進めましょう」)。Opus のレビューを経て承認にする)
- 関連: [ADR 0001](0001-manga-face.md) D2・D3・D4・D6・D7・実装計画、[ADR 0002](0002-reference-guided-faces.md) D6・D9、[ADR 0003](0003-part-curve-fitting.md) D4
- この ADR が改訂するもの: ADR 0001 の D4(スタイル)と D7 の検査の一部、実装計画の U3 の確認点 2 以降。D2 のパラメータの型、D3 の表情の仕組み、D5(決定性と API)、D6(権利)は変えない

## 背景

ADR 0001 の U2・U3 は、色付きのセル塗りの顔(肌・髪・服の 3 色、紙色のキーライン)を実装した。その後、ADR 0002 の参考画像を使った試作(2026-11-23〜24。非公開の作業記録)で、owner は白黒の線画の描き方を選んだ。試作で分かったこと:

1. **線画の方が owner の目標に近い**。参考に当てはめた 4 人、顔の描き方を共通にした 24 人、部品 30 種(髪 12、目・眉・口 各 6)を作り、owner は「別人に見える」「表情が分かりやすい」と評価した。
2. **目と髪の描き方を作り直すと、大きく良くなる**。ボブの 2 人で、目尻で太く外へ伸びる上まぶた、細く途切れる下まぶた、縦長の虹彩と大小のハイライト、頬に沿う房と線の入り・抜きの細り、を描いた版に、owner は「かなり良くなりました」と評価した。
3. **表情の候補を owner が選んだ**: 目を開いた穏やかな笑顔(G6: 瞳を少し下げ、下まぶたを上げる、浅い弧の口)、目を閉じた笑顔(S4)、驚き(A4)。
4. **ただし、試作の形はそのまま出荷できない**。目の形の数値は参考画像に合わせて決めた。髪は、参考画像の上で 1 人ずつ手で置いた点の列(房 11 本 × 約 8 点)で、ADR 0002 D6・ADR 0003 D4 が出荷を禁じる「個別の画像を再構成できる点列」にあたる。

owner は 2026-11-25 に、色付きの描き方はもう使っていないと述べた。

## 決定

### D1. 白黒の線画に置き換える(色付きの描き方は、切り替えのあとで消す)

- **見た目の目標は白黒の線画**。インク(`#22201b`、コマのインクと同じ)と紙(`#ffffff`)、虹彩の中間の灰色 1 つ。セル塗りの影、肌・髪・服の塗り、紙色のキーラインは使わない。
- **線の体系**: 輪郭(顔・首・胴・耳)は一定幅のストローク。目のまぶた、眉、髪の房とその区切りは、**先の細い塗りの形**(中心線に沿って幅を変え、入りと抜きを細くする)。開いた線の最小幅は ADR 0001 D4 と同じ 2.8 単位(舞台で 1.0 px)。
- **髪は前に重なる線**。顔の上にかかる房は顔の線より前に描き、房の内側は紙で塗る(下の線を隠す)。
- **色付きの描き方は残さない**。2 系統を持つと、golden・測定・確認点が 2 倍になり、owner が使わない方を保守することになる。D5 の切り替えのあと、色付きの描画とその検査(キーライン、ピクセルのコントラスト)を消す。
- **`palette` は型に残す**(v1 の線画では描画に使わない)。マニフェストの互換を保ち、あとで塗りを足すときの入口にする。`validate` と `normalize` の扱いは変えない。

### D2. 目と顔は、言葉の仕様から描き直す(試作の数値を写さない)

ADR 0001 D6 の「参考画像に合わせた形を、そのまま出荷物に入れない」を守る。試作のコード・座標・SVG は、実装者に渡さない。実装者が受け取るのは、次のような**言葉の幾何の仕様**と、ADR 0001 D2 の座標系だけ:

- **目**: 開口は、上の弧が高く下の弧が浅い、目尻側がやや尖る形。上まぶたは目頭で細く、目尻で太くなり、目尻の外へ短く跳ねる(まつげの塊を兼ねる)。二重の線は上まぶたの上に細く 1 本。下まぶたは細い線で、目尻寄りの一部だけを描き、目頭側は途切れる。虹彩は縦長の楕円で開口に切り抜かれ、外側の濃い輪、中間の灰色、濃い瞳の 3 層。ハイライトは大(上)・小(下)・点の 3 つ。左右は鏡像。
- **顔**: 頬からあごへの線は 1 本のストローク。あご先は人物の `head` のパラメータ(ADR 0001 D2)で決まる。耳は輪郭の外に、内側の線 1 本。鼻は短い影の線、口は表情の形(D4)。
- **人物の差**: 目の位置・幅・高さ・傾き、虹彩の大きさ、あごの形は、ADR 0001 D2 のパラメータのまま。新しい形を足すときは、パラメータを足して範囲を決める(ADR 0001 D2 の規則)。

**確かめ方**: 実装の PR のレビューで、Claude が手元の試作のファイルと `src/` の数値の列を照合する道具(非公開。公開リポジトリには入れない)を走らせ、連続する 4 つ以上の座標の一致が無いことを確かめ、レビュー記録に結果を書く。

### D3. 髪は、パラメータで描く房のモデルにする

試作の点の列は出荷しない。代わりに、房を**パラメータから生成する**:

- **ボブ**: 分け目の位置、前髪の房の数、頬に沿う房の数と曲がり、毛先の巻き込み(内向きの曲がりの強さ)、長さ(あご・あごの下・肩の手前)、横のふくらみ、耳の見え方(隠す・少し見せる)。
- **短髪**: 分け目、前髪の房の数、頭頂の高さ、横の刈り上げの長さ、毛先の向き。
- 房は、根元と毛先の位置、中心線の曲がり、幅と先細りを持つ。根元の並び、前後の重なり、自己交差しないことは、ADR 0001 D2 の不変条件と同じく `validate` で検査する。
- **既定値と範囲はコードで決めた値から始める**。参考への当てはめ(ADR 0003 D2)は、モデルの形を選ぶため(どの自由度が要るか)にだけ使い、その値は非公開に置く。出荷する既定値・範囲を当てはめから作るのは、方向ごとに独立した参考が 10 件以上そろってから(ADR 0002 D6 の 2)。
- 試作の髪 12 種(結び髪・ツインテール・編み込みなど)は、見た目の下書きとして見てよいが、形は D2 と同じく言葉の仕様から描き直す。

### D4. 表情: 試作で選んだ 3 つを 8 表情に当て、残りを同じ描き方で作る

| ADR 0074 の表情 | 線画での形 |
|---|---|
| `neutral` | 基準 |
| `smile` | G6: 目を開いたまま、瞳を少し下げ、下まぶたを上げる。口は浅い弧 |
| `laugh` | S4: 目を閉じた笑顔の弧、口を開く |
| `surprise` | A4: 目を大きく、虹彩を小さく、眉を上げる、小さな丸い口 |
| `worry` `angry` `think` `sad` | ADR 0001 D3 の差分の意味を保ち、線画の部品で描き直す。owner が段 L3 で確認する |

表情の仕組み(人物の基本への差分、ADR 0001 D3)と、追加の表情の `expressionMap` は変えない。

### D5. 段ごとに作り、owner の確認のあとで切り替える

線画は、公開の入口とは別のモジュール(`src/line/`)で作り、道具(`tools/`)のギャラリーからだけ使う。golden と `pnpm measure --check` は、切り替えまで色付きのまま保つ(壊れていないことの検査を途切れさせない)。

| 段 | 内容 | owner の確認 |
|---|---|---|
| L1 | 顔・目・眉・鼻・口の線画(D2)。仮の髪(頭の外形 1 本)で、`neutral` `smile` `laugh` `surprise` | 原寸と舞台の大きさで、目の印象と 3 表情 |
| L2 | 髪: ボブと短髪(D3) | 髪の形、2 人以上で描き分けられるか |
| L3 | 残りの 4 表情(D4)。舞台の大きさの見分けやすさの検査(D6) | ブラインドの確認(ADR 0001 D7) |
| 切り替え | `faceFragment` を線画に替え、色付きの描画と検査を消す。`hair.template` を、線画で実装した型(`bob` `short`)に絞り、`GENERATOR` を上げる(ADR 0001 U5)。golden を作り直す。README と ADR 0001 の状態の行を直す | 切り替えの PR の前後の画像 |
| L4 | ほかの髪型(長い髪、巻き髪、結び髪など)を 1 種ずつ足す | 1 種ごと |

- ADR 0001 の U3 の確認点 2(色付きの髪)は行わない。U4(追加の表情)・U5(乱数)・U6(ギャラリーと CLI)は、切り替えのあとで線画に合わせて再開する。Issue #4・#5・#6 の仕様は、そのとき書き直す。
- 各段は Sonnet の実装者に `impl-task` で渡し、Opus がレビューする(AGENTS.md)。

### D6. 検査を線画に合わせる

| ADR 0001 D7 の基準 | 線画での扱い |
|---|---|
| 読み込み・不変条件・アンカー・差し替えの互換・大きさ・決定性・禁止要素 | そのまま |
| 最小の線幅 | そのまま(先の細い塗りの形は、入りと抜きを除き、幅の中央値で 2.8 単位以上) |
| コントラスト(ピクセル)・キーラインの効き | 消す(塗りが無く、線は紙の上にある) |
| 見分けやすさ(機械) | 同じ測り方。しきい値 6 は色付きで決めた値なので、L3 で線画の値を測って報告し、owner が新しいしきい値を決める。決まるまで、切り替えをしない |
| 見分けやすさ(人) | そのまま(ブラインドの確認、対象ごとに 8 中 7 以上) |
| 線の重なり(新規) | 髪の房が目と眉の上に重ならない(前髪が眉にかかるのは許し、目の開口には入らない)。全表情・髪の全パラメータの格子で検査する |

## 代替案

- **色付きと線画を選べるように残す**: owner が色付きを使っていない。2 系統の保守と検査の重さに見合わない。塗りが要るときは、線画に塗りを足す(D1 の `palette`)。
- **試作の数値をそのまま使い、ADR 0001 D6 を改訂する**: 目は早く良くなるが、「参考に合わせた形を出荷しない」約束を崩す。髪の点の列は、ADR 0002 と 0003 がはっきり禁じている。
- **一度に全部を置き換える**: 確認点が 1 つにまとまり、どこが悪いか分からなくなる。golden と測定の検査も途切れる。

## 影響

- 公開の描画が変わる(切り替えの PR)。`hair.template` の値が一時的に減る(0.x の破壊的変更。README に書く)。
- 測定の道具から、キーラインとコントラストの検査が消える。見分けやすさのしきい値は owner が決め直す。
- 試作の作業記録は、非公開の参考リポジトリの `trials/2026-11-24/` に置いた(ADR 0003 D4 の扱い)。
