# ADR 0004: 描き方を白黒の線画に移す — 言葉の仕様から描き直す目と顔、パラメータで描く房、段ごとの切り替え

- 状態: **承認**(2026-11-27。owner 承認。Opus のレビュー 4 回で収束: Blocker・Major・Minor・nit なし)
- 関連: [ADR 0001](0001-manga-face.md) D2・D3・D4・D6・D7・実装計画、[ADR 0002](0002-reference-guided-faces.md) D6・D9、[ADR 0003](0003-part-curve-fitting.md) D4
- **この ADR が改訂するもの**(ADR 0001): D2 の髪の型と目の不変条件(D3 に書く)、D4(スタイル: 塗り・キーライン・パレット・`recolor`)、D7 の検査の一部(D6 に書く)、実装計画の U3 の確認点 2 以降と U7 の完了条件。**変えないもの**: D2 の髪以外の型と座標系、D3 の表情の仕組み(切り替えのあと、プリセットの表は 1 つ。それまでは線画の差分を `src/line/` に置く。D4)、**眉は前髪の上に描く**こと、D5(決定性と API)、D6(権利)

## 背景

ADR 0001 の U2・U3 は、色付きのセル塗りの顔(肌・髪・服の 3 色、紙色のキーライン)を実装した。その後、ADR 0002 の参考画像を使った試作(2026-11-23〜24。非公開の作業記録)で、owner は白黒の線画の描き方を選んだ。試作で分かったこと:

1. **線画の方が owner の目標に近い**。参考に当てはめた 4 人、顔の描き方を共通にした 24 人、部品 30 種(髪 12、目・眉・口 各 6)を作り、owner は「別人に見える」「表情が分かりやすい」と評価した。
2. **目と髪の描き方を作り直すと、大きく良くなる**。ボブの 2 人で、目尻で太く外へ伸びる上まぶた、細く途切れる下まぶた、縦長の虹彩と大小のハイライト、頬に沿う房と線の入り・抜きの細り、を描いた版に、owner は「かなり良くなりました」と評価した。
3. **表情の候補を owner が選んだ**: 目を開いた穏やかな笑顔(G6: 瞳を少し下げ、下まぶたを上げる、浅い弧の口)、目を閉じた笑顔(S4)、驚き(A4)。
4. **ただし、試作の形はそのまま出荷できない**。目の形の数値は参考画像に合わせて決めた。髪は、参考画像の上で 1 人ずつ手で置いた点の列で、ADR 0002 D6・ADR 0003 D4 が出荷を禁じる「個別の画像を再構成できる点列」にあたる。

owner は 2026-11-25 に、色付きの描き方はもう使っていないと述べた。

## 決定

### D1. 白黒の線画に置き換える(色付きの描き方は、切り替えのあとで消す)

- **出力の色は 3 つだけ**: インク(`#22201b`、コマのインクと同じ)、紙(`#ffffff`)、虹彩の中間の灰色 1 つ(インクと紙の間の固定値。L1 で決めて定数にする)。セル塗りの影と、肌・髪・服の色の塗りは使わない。
- **紙で裏打ちする**: 顔・耳・首・胴・後ろ髪・前髪の房の内側は、**紙(`#ffffff`)で不透明に塗る**。透明にしない。コマの色(`bg.tint`)やダークモードの背景が顔の中に透けないため(ADR 0001 D4 の「紙の色」の約束は、そのまま)。
- **重ねる順**: 後ろ髪 → 胴・首 → 顔・耳 → 前髪の房(紙の塗り + インクの線)→ 目 → **眉**(前髪の上。ADR 0001 の「眉を前髪の上に出す」を保つ)→ 鼻・口・頬の斜線。前髪は目の開口に入らない(D6 の検査)。
- **眉の縁取り**: 眉が前髪の房の線と重なる所で見分けられるよう、眉の下に紙の線(両側に 2 単位太い)を敷く。紙の上では見えず、房の線の上でだけ効く。
- **線の体系**: 輪郭(顔・首・胴・耳)は一定幅のストローク。目のまぶた、眉、髪の房とその区切りは、**先の細い塗りの形**(中心線に沿って幅を変え、入りと抜きを細くする)。開いた線の最小幅は ADR 0001 D4 と同じ 2.8 単位(舞台で 1.0 px。測り方は D6)。
- **色付きの描き方は残さない**。2 系統を持つと、golden・測定・確認点が 2 倍になり、owner が使わない方を保守することになる。D5 の切り替えで、色付きの描画とその検査(境目のキーライン)を消す。
- **`palette` は入力の型に残す**(線画の v1 では描画に使わない)。既存の人物の JSON がそのまま `validate` を通るため(入力の互換)。マニフェストの互換とは関係しない。あとで塗りを足すときの入口にする。

### D2. 目と顔は、言葉の仕様から描き直す(試作の数値を写さない)

ADR 0001 D6 の「参考画像に合わせた形を、そのまま出荷物に入れない」を守る。

**実装者に渡すもの**: 次のような**言葉の幾何の仕様**と、ADR 0001 D2 の座標系だけ。

- **目**: 開口は、上の弧が高く下の弧が浅い、目尻側がやや尖る形。上まぶたは目頭で細く、目尻で太くなり、目尻の外へ短く跳ねる(まつげの塊を兼ねる)。二重の線は上まぶたの上に細く 1 本。下まぶたは細い線で、目尻寄りの一部だけを描き、目頭側は途切れる。虹彩は縦長の楕円で開口に切り抜かれ、外側の濃い輪、中間の灰色、濃い瞳の 3 層。ハイライトは大(上)・小(下)・点の 3 つ。左右は鏡像。
- **顔**: 頬からあごへの線は 1 本のストローク。あご先は人物の `head` のパラメータ(ADR 0001 D2)で決まる。耳は輪郭の外に、内側の線 1 本。鼻は短い影の線、口は表情の形(D4)。
- **人物の差**: 目の位置・幅・高さ・傾き、虹彩の大きさ、あごの形は、ADR 0001 D2 のパラメータのまま。

**実装者に渡さないもの**: 試作のコード・座標・SVG・画像と、参考画像。

- `impl-task` のタスク仕様に「非公開の参考リポジトリ(`manga-face-refs`)と試作の作業記録を開かない」と書く。実装者は PR 本文で、開いていないことを明記する。
- **owner の確認は、線画の出力だけを見る**(原寸と舞台の大きさ。参考画像や試作を横に並べない、重ねない)。見た目の指摘は好みの判断として**言葉で**実装者に渡す(「目尻の跳ねを短く」など)。出荷する形を 1 枚の参考に近づける調整(参考との重ね合わせ、参考ごとの差を見ての直し)はしない(ADR 0001 D6、ADR 0002 D6 の 2: 参考の影響は、方向ごとに 10 件以上の集計を通してだけ)。

**照合の検査(クリーンルームの確認)**:

- 道具は非公開の参考リポジトリに置く(`tools/cleanroom_check.py`。試作のデータを読むので公開リポジトリには置けない)。Claude が L1 の最初のレビューの前に作り、試作の点の列そのもの・拡大した写し・0.1 に丸めた写しを失敗にできること(負の対照)を確かめてから使う。参考リポジトリを読める人なら、誰でも同じ結果を再現できる。
- 方法: 線画の出力(D5 の段ごとの golden と、髪の全パラメータの格子で描いた SVG)から、すべてのパスの点の列を取り出す。試作のすべての点の列(目・顔・髪の房・アクセントの線)と、**相似変換(平行移動・回転・拡大)で最もよく重ねたうえで**比べる。比べるのは点そのものではなく**曲線**: 両方の線を弧長で等間隔に取り直し(輪郭の線は、太さを持つ形なら中心線に戻してから)、相似変換で重ねたあと、どちらかの線の 20% 以上の長さの区間が、形の大きさの 2% 以内(離散フレシェ距離)で一致したら失敗にする。負の対照: 試作の線そのもの、拡大した写し、0.1 に丸めた写し、中心線を取り直してスプラインと太さを付け直した写しが、すべて失敗になること。
- 実行するのは、L1〜L4 の各 PR と切り替えの PR のレビュー。Claude が走らせ、結果(比べた列の数、最も近い一致の距離)をレビュー記録に書く。

### D3. 髪は、パラメータで描く房のモデルにする(ADR 0001 D2 の髪の型を改訂する)

試作の点の列は出荷しない。房を**パラメータから生成する**。

**髪の型**(切り替えで `Base['hair']` をこれに替える):

| 項目 | 型・範囲 | 刻み | 既定(young / mature) | 意味 |
|---|---|---|---|---|
| `template` | `'bob' \| 'short'`(L4 で増やす) | — | `short` / `short` | 髪型 |
| `strands` | 1〜9 | 1 | 4 / 5 | 前髪の房の数(ADR 0001 と同じ名前・範囲) |
| `parting` | −1〜1 | 0.25 | 0.5 / 0.5 | 分け目の位置(ADR 0001 と同じ) |
| `ahoge` | `'none' \| 'left' \| 'right'` | — | `none` | 頭頂の跳ねる房 1 本(ADR 0001 と同じ) |
| `cheekLocks` | 0〜3 | 1 | 0 / 0(bob の既定は 2) | 頬に沿う房の数(片側) |
| `tipCurl` | 0〜1 | 0.1 | 0.5 | 毛先の内向きの巻き込み |
| `length` | 0〜1 | 0.1 | 0.3 / 0.2 | 横と後ろの長さ。`short` は耳の上〜耳の下、`bob` はあご〜肩の手前に写す |
| `volume` | 0〜1 | 0.1 | 0.4 / 0.3 | 横のふくらみ |
| `ears` | `'hidden' \| 'peek'` | — | `peek` | 耳を見せるか |

- **消す項目**: `highlight`(線画にはツヤの帯が無い。房の中の細いアクセントの線は、房の数から決める)、`sideLen`(`length` に置き換える)。
- 既定値と範囲は、上の表から始める(コードで決めた値)。参考への当てはめ(ADR 0003 D2)は、モデルの形を選ぶため(どの自由度が要るか)にだけ使い、その値は非公開に置く。出荷する既定値・範囲を当てはめから作るのは、方向ごとに独立した参考が 10 件以上そろってから(ADR 0002 D6 の 2)。表の値を変えるのは、L2 の owner の確認(線画の出力だけを見た好みの判断。D2)か、この ADR の改訂で。
- **不変条件**(`validate`): 房の外形と中心線が自己交差しない、根元の並びが分け目から外へ順に並ぶ、前髪が目の開口に入らない、頭頂が `top ≥ 23` を保つ。
- **乱数と正規化**: L2 で `RANGES` と `normalize` に新しい項目を足す(`src/line/` の中で)。切り替えで、`randomCharacter` の髪の群を新しい型で引くように替え、`GENERATOR` を上げ、固定シードのスナップショットを作り直す(ADR 0001 U5 の規則)。古い型の入力(`highlight` `sideLen` と、`long` `wavy` の `template`)は、切り替えのあと `normalize` が新しい型に移す: `length = round((sideLen − 16) / 24, 0.1)`、`long` → `bob`(`length` 1)、`wavy` → `short`、`highlight` は捨てる。移せる古い値は誤りにしない(`validateRaw` も報告しない。README に移し方を書く)。範囲の外の古い値は、今までどおり `validateRaw` が報告する。`ears` は `length` と独立(`peek` でも、長い髪は耳の前に房を描き、耳の上半分だけを見せる)。
- 試作の髪 12 種(結び髪・ツインテール・編み込みなど)は、owner との見た目の会話にだけ使い、形は D2 と同じく言葉の仕様から描き直す。

**目の不変条件の改訂**(ADR 0001 D2): 目の形が変わり(目尻の跳ね)、目の外接の形が広がる。「目が顔の中」「眉と目の間」の検査は、跳ねを含めた外接で行い、L1 で範囲(`eyes.w` `eyes.gap` の組み合わせ)を測り直して、範囲の端で不変条件が守られるように直す。

### D4. 表情: 試作で選んだ 3 つを 8 表情に当て、残りを同じ描き方で作る

- **切り替えまで、公開の表と検査は動かさない**(色付きの出力をバイト単位で保ち、`GENERATOR` 4 のまま)。線画は `src/line/` の中に、公開の `PRESETS` `RANGES` `normalize` `validate` への**上書き**(線画専用の差分・範囲・不変条件)を持ち、公開のものを読んだうえで上書きを当てる。L1〜L3 の受け入れ条件の `validate` は、この線画の検査(`lineValidate`)を指す。切り替えで上書きを公開の表に合わせ、`src/line/` の上書きを消し、`GENERATOR` を上げる。
- **頬の斜線**(`blush`)は、インクの短い斜線として残す(白黒のマンガの慣習)。

| ADR 0074 の表情 | 線画での形 |
|---|---|
| `neutral` | 基準 |
| `smile` | G6: 目を開いたまま、瞳を少し下げ、下まぶたを上げる(`squint`)。口は浅い弧。頬の斜線 |
| `laugh` | S4: 目を閉じた笑顔の弧、口を開く。頬の斜線 |
| `surprise` | A4: 目を大きく、虹彩を小さく、眉を上げる、小さな丸い口 |
| `worry` `angry` `think` `sad` | ADR 0001 D3 の差分の意味を保ち、線画の部品で描き直す。owner が段 L3 で確認する |
| 追加の 6 表情 | 同じく ADR 0001 D3 の意味(`><` の目、点の目、半目など)を保ち、L3 で描き直す。切り替えのあとも `expressionMap` で使える |

追加の表情の `expressionMap` は変えない。

### D5. 段ごとに作り、owner の確認のあとで切り替える

線画は、公開の入口とは別のモジュール(`src/line/`)で作る。公開の `index.ts` からは出さず、道具(`tools/`)からだけ使う。色付きの golden と `pnpm measure --check` は、切り替えまでそのまま保つ。

**どの段でも守る機械の条件**(L1 の最初の PR で入れる):

- `test/purity.test.ts` を `src/` の下の全ディレクトリに広げる(いまは `src/` の直下だけを見ていて、`src/hair/` も漏れている)。
- 線画の golden を `goldens/line/` に足し、`pnpm golden` が色付きと線画の両方を比べる(線画の golden は段ごとに意図して作り直す。AGENTS.md の golden の規則)。
- `pnpm measure --check` に線画の節を足す: 決定性(Node 2 回・Chromium)、最小の線幅、アンカー、不変条件、D6 の特徴の線の検査、大きさ。

| 段 | 内容 | 機械の受け入れ条件 | owner の確認 |
|---|---|---|---|
| L1 | 顔・目・眉・鼻・口の線画(D2)。仮の髪(頭の外形 1 本)で、`neutral` `smile` `laugh` `surprise` | 上の共通の条件。`head` と `eyes` の範囲の格子 × 4 表情で `lineValidate` が空。色付きの golden・スナップショット・`measure --check` は変わらない、目の不変条件(D3 の改訂)が通る、範囲の外の 1 歩で落ちる | 原寸と舞台の大きさで、目の印象と 3 表情 |
| L2 | 髪: ボブと短髪(D3) | D3 の不変条件を、髪の全項目の格子(各項目の端と中央)× 2 型 × 4 表情で検査。`top ≥ 23`。房の幅が分け目からの距離で変わる(数値で) | 髪の形、2 人以上で描き分けられるか |
| L3 | 残りの 4 表情と、追加の 6 表情(`shy` `smug` `deadpan` `clench` `cry` `blank`。`expressionMap` で使えるもの)(D4) | 14 表情で上の条件。見分けやすさ(機械)を 8 表情で測って報告(D6) | ブラインドの確認(ADR 0001 D7、8 表情)。追加の 6 表情の見た目。見分けやすさのしきい値を決める |
| 切り替え | `faceFragment` を線画に替え、色付きの描画と検査を消す。髪の型を D3 に替え、`GENERATOR` を上げる。色付きの golden を消す。README・`PROVENANCE.md`・ADR 0001 の状態の行を直す | ADR 0001 D7 の全基準(D6 の改訂後)が通る。差し替えの互換(内蔵の顔で通る `comic()` の例が落ちない) | 切り替えの PR の前後の画像 |
| L4 | ほかの髪型(長い髪、巻き髪、結び髪など)を 1 種ずつ足す | L2 と同じ格子の検査を、その型で | 1 種ごと |

- ADR 0001 の U3 の確認点 2(色付きの髪)は行わない。追加の表情の線画は L3 で作る(切り替えで公開の機能を落とさない)。U4 のうち残り(追加の表情の見直しと、台本から名指しする拡張の準備)・U5(乱数)・U6(ギャラリーと CLI)は、切り替えのあとで線画に合わせて再開する。Issue #4・#5・#6 の仕様は、そのとき書き直す。
- 各段は Sonnet の実装者に `impl-task` で渡し、Opus がレビューする(AGENTS.md)。クリーンルームの照合(D2)は、L1・L2・L3・L4 と切り替えのレビューで行う。
- `PROVENANCE.md` の線画の部品の行: 「Written by」は「coding assistant (Claude Sonnet) from the verbal geometry spec in ADR 0004 D2/D3」、参考の列は「verbal spec distilled by Claude from a private prototype fitted to reference images (ADR 0004 background); no coordinates copied; clean-room check YYYY-MM-DD」とし、照合の日を書く。

### D6. 検査を線画に合わせる(ADR 0001 D7 の改訂)

| ADR 0001 D7 の基準 | 線画での扱い |
|---|---|
| 読み込み・不変条件・アンカー・差し替えの互換・大きさ・決定性・禁止要素 | そのまま(不変条件には D3 の髪と目の改訂を足す) |
| 最小の線幅 | ストロークはそのまま。先の細い塗りの形は、中心線に沿って長さの 20〜80% の間を 10 点で測り、すべての点で幅 2.8 単位以上 |
| 特徴の線のピクセル検査 | **残す**。舞台の 3 倍で描き、眉・鼻・口・`^^` `><` 点の目のインクの縁の周囲 2〜4 px に紙が見える割合を測る。L1 では、仮の頭の 3 人(ADR 0001 の `CHARACTERS` の a・b・m の顔のパラメータ)で、眉以外の特徴の線と眉の紙の縁取りの有無だけを測る(髪が無いので、眉と前髪の交わりの数の条件は L2 から)。L2 からの対象の人物は、手で決めた 3 人(young の bob・short、mature)と、`strands` 9・`length` 0 の前髪が眉にかかる人物 1 人。× 全表情、背景は白と、コマの濃い色(`bg.tint` の最も暗い値)の 2 通り。基準は ADR 0001 と同じ(各 85% 以上、全体 95% 以上)。負の対照: 眉の紙の縁取りを外すと、前髪の上の眉で落ちる。対照が意味を持つよう、眉が前髪の房の線と交わる組が、対象の中に少なくとも 8 件あることを測定が数えて報告し、8 件未満なら検査を失敗にする |
| 境目のキーラインの効き | 消す(塗りの境目が無い) |
| 見分けやすさ(機械) | 同じ測り方。**しきい値はすべて L3 で決め直す**: 手で決めた人物の最小(いま 6)、乱数とパラメータの両端の最小(いま 3.5)、自分の中央値に対する比(いま 0.5)。「パレットの両端」は、色が無いので「髪の型 × `length` `volume` の両端 × 目の範囲の両端」に替える。L3 で値を測って報告し、owner が決める。決まるまで切り替えをしない |
| 見分けやすさ(人) | そのまま(ブラインドの確認、対象ごとに 8 中 7 以上) |
| 前髪と目(新規) | 前髪の房が目の開口に入らない。髪の全パラメータの格子 × 全表情で検査(`validate` の不変条件) |

### D7. `recolor` と svg-diagram との接続(ADR 0001 D4・U7 の改訂)

- 線画の v1 は、肌・髪・服の色を出さない。ADR 0076 の `recolor` が差し替える色のスロットが無いので、**`recolor` は線画の顔では何も変えない**(壊れはしない)。線画のマニフェストは `recolor` の色を宣言しない。svg-diagram の ADR 0076 では、`avatars` は素材の顔に、宣言された `recolor` の色を通してだけ効くので、線画の顔に `avatars` を当てると `comic-avatar-ignored` の案内が出て、絵は変わらない。人物を描き分けたいときは、パラメータの違う人物を作る。
- ADR 0001 U7 の完了条件のうち「`recolor` で色が変わる」は、「`recolor` を通しても出力が `loadCharacter` を通り、絵が変わらない」に改める。色を変えたいときは、D1 の `palette` から塗りを足す後続の ADR で扱う。
- U7 は svg-diagram の側の確認が要るので、U7 のタスク仕様を書くときに svg-diagram の ADR 0076 の扱い(色の無い素材の顔)を確かめる。

## 代替案

- **色付きと線画を選べるように残す**: owner が色付きを使っていない。2 系統の保守と検査の重さに見合わない。塗りが要るときは、線画に塗りを足す(D1 の `palette`)。
- **試作の数値をそのまま使い、ADR 0001 D6 を改訂する**: 目は早く良くなるが、「参考に合わせた形を出荷しない」約束を崩す。髪の点の列は、ADR 0002 と 0003 がはっきり禁じている。
- **一度に全部を置き換える**: 確認点が 1 つにまとまり、どこが悪いか分からなくなる。golden と測定の検査も途切れる。
- **前髪を眉の上に描く**(試作の一部の描き方): 1 回目の診断で、眉が前髪に隠れると表情が混ざった(ADR 0001 D3)。眉を上に保ち、紙の縁取りで房の線から分ける。

## 影響

- 公開の描画が変わる(切り替えの PR)。髪の型が変わり、`hair.template` の値が一時的に減る(0.x の破壊的変更。古い入力は `normalize` が移す。README に書く)。
- `recolor` は線画の顔で何も変えなくなる(D7)。
- L1 で目の範囲(`eyes.w` `eyes.gap` など)を狭めた場合、切り替えのあと、既存の人物の JSON の範囲の外の値は `normalize` が範囲の端に丸める(ADR 0001 D2 の規則どおり)。見た目が変わるので、切り替えの PR と README に、変わった範囲を書く。
- 測定の道具から、境目のキーラインの検査が消える。見分けやすさのしきい値は owner が決め直す。
- 試作の作業記録と照合の道具は、非公開の参考リポジトリに置く(ADR 0003 D4 の扱い)。
